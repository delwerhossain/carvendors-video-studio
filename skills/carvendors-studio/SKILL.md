**Primary brand:** CarVendors.co.uk · **Featured dealer:** B&F Cars, Northampton
**Output:** 1080 × 1920 (9:16), British English on screen · **Talk to the user:** short, clear Bangla

### 2.1 Fast lane — one job.json per video (default for bulk)

`python3 $CS/tools/build.py <job.json> [--render]` builds everything from a small JSON: clean master (cached),
hook played in full → one transition → full main video → outro, fixed `logo-badge`, `text-cover` boxes, optional
overlays, music (+ voice ducking), light grain, then `npx hyperframes check`; `--render` also renders, masters
to −14 LUFS, writes `output/<id>_<slug>_carvendors_vN.mp4` (never overwrites) and a frame sheet.
The full schema is in the docstring of `build.py`. Minimal example:
```json
{ "id": "v002", "slug": "mitsubishi-asx", "folder": 2,
  "clean": {"boxes": [], "grade": "eq=contrast=1.05:saturation=1.07:gamma=0.98"},
  "hook": {"file": "Soccer-Tire.mp4", "in": 2.0, "out": 5.75}, "transition": "cut",
  "logo": {"corner": "top-left", "style": "dark"},
  "covers": [{"at": 0, "dur": "all", "x": 135, "y": 1305, "w": 810, "h": 230, "text": "Dad’s next car?"}],
  "overlays": [{"component": "hero-model", "at": 0.2, "dur": 2.6, "vars": {"make": "MITSUBISHI", "model": "ASX", "x": 870, "y": 300, "align": "right", "size": 175, "scrim": 0.4}}],
  "music": {"file": "Royalty Free Music/NCS/Syn_Cole_-_Feel_Good_[NCS_Release].mp3", "start": 42.0, "volume": 0.6},
  "outro": {"photo": "front-side-view.png", "dur": 3.0, "focus": "72% 50%"} }
```
**Token budget per video** (do only this unless something fails): `ffprobe` + ONE contact sheet (10-12 frames)
+ locate old text boxes (one numpy pass or one crop) + Whisper only if the source has speech → write job.json
→ `build.py` → `snapshot` 4-5 frames (look once) → fix the JSON if needed → `build.py --render` → look at the
frame sheet. Reuse the same hook/music/outro choices across a batch where they fit; vary the overlay text.

## 3. Classify before editing (no single template)

Sample 8–12 frames (contact sheet), detect cuts, transcribe audio, read comments, then pick:

| Type | Structure | Treatment |
|---|---|---|
| **A. Vehicle showcase** | hook → hero/model → details → exterior/interior → CTA | cinematic type, rare shape-text, ≤2 verified features |
| **B. Educational** | question/claim → explanation → demonstration → takeaway → CTA | accurate captions, one concept line at a time |
| **C. Walkaround / presenter** | best spoken/visual moment → B-roll → key benefit → CTA | keep the real voice, subtle captions, few labels |
| **D. Sold / success story** | engaging hook → vehicle → confirmed outcome → service CTA | `SOURCED & SOLD` only with evidence |

Length follows the story (commonly 12–30 s). Never force five scenes or fake angles.

## 4. Hooks — play the hook in full, then ONE transition into the main video

1. Hooks live in the `hooks` folder (`paths.py get hooks`, ≈40 short action clips). Pick by energy and relevance;
   obey a named hook. Check rights: third-party viral clips can be claimed on Meta/YouTube; prefer owned clips.
2. **Play the whole action:** setup → action → payoff (the moment that makes people keep watching). Trim only
   dead time before the setup and after the payoff (typical 2-5 s). Find the action from one frame sheet + the
   audio peak; set `hook.in` / `hook.out` in job.json. No logo, captions or sales text on the hook.
3. **Then exactly one transition** on the hook's last frame (`transition` in job.json): `cut` (default, with a
   1.07→1.00 settle punch on the main video) · `whip` (only if the hook's motion goes sideways) · `flash` (on an
   impact) · `zoom` (on a push-in/impact toward camera). Never stack two.
4. The main video starts from its own first frame (usually the hero front 3/4). A branded hero opening without
   an external hook is also allowed (then `hook` = null and a `hero-model` overlay at 0.2 s).

## 5. Design system (follows the v3.1 brief)

### 5.1 Composition
- **Car first:** no text over bonnet, grille, headlights, wheels, badges, key details or a speaker's face.
- Find real negative space (sky, plain wall, floor, soft interior) per shot; position per shot, not fixed XY.
- Some shots carry only the car + tiny logo. **One headline system per shot** (`hero-model` OR `shape-text`
  OR `detail-line` OR `verified-feature`). No dense infographics or tall lists on a moving car.

### 5.2 Modes
- **A — Minimal cinematic hero (default first shot):** `logo-top` + `hero-model` (small spaced make line +
  very large model, 140–235 px, fitted to the sky/wall above the car).
- **B — Detail / shape-text:** `detail-line` ("In the / details." + tiny green dot) on a tight real close-up,
  or one `shape-text` line ("Iconic Abarth" + [Style]); small, rare accent pill, optional −3…−4° tilt.
- **C — White intro card:** rescue layout only for cluttered footage; never by default.

### 5.3 Colour
White text; charcoal `#111311` for scrims/backings; authentic logo green (`#7AC943`) only as tiny markers;
accent derived from the actual paint, muted, ≤10–15 % of graphic area. White/silver/black cars → neutral or
tiny green accent. Natural grade; preserve paint; no oversaturation. A red car ≠ red everything.

### 5.4 Typography
Oswald 700 for big numbers/display; Manrope 400/700 for everything else (or Manrope 700 + Source Sans for a
softer car — still two families max). Starting sizes at 1080×1920: hero 140–235 px, title 64–92, heading
46–68, caption 42–56, label 28–36. Line height 0.95–1.12 display, 1.15–1.30 reading. UK English only.

### 5.5 Legibility on moving footage
Test each text region across its whole duration (brightest and busiest frames). Clean sky/wall → plain white.
Busy → `localized-contrast` (charcoal → transparent, 30–55 %, confined to the text). Very busy → small dark
backing on the text only. Never blur the whole frame or the car. Targets: 4.5:1 small text, 3:1 large
(`npx hyperframes check` must pass; fix by position/size/scrim first). Max two short verified tick lines.
If it still fails: move, shorten, delay, change shot, or show nothing.

### 5.6 Safe zones (1080 × 1920 guide)
Text x 80–870, y 230–1500; keep key text out of the bottom ~320 px and the right action rail. Logo upper-left
or upper-centre. Captions above the bottom UI. Safe zone never justifies covering the car.

### 5.7 Motion
Entrances 200–350 ms (opacity + 8–20 px slide or mask rise), exits 120–250 ms, ease-out. Hold key words ≥1–1.5 s.
One animation focus at a time. Glass only on tiny labels (no big glass cards). Graphics leave with their shot.

### 5.8 Old TikTok text — decide per text, cheapest good option first

Old B&F videos carry burned-in text. Treat each text box once for the whole video:
1. **Keep it** when it is harmless, readable and on-brand (e.g. a plain model name "Abarth 595"). Zero cost.
2. **Must go** when it shows prices/finance, mentions TikTok, names another business, is off-brand or rude,
   makes an unverified claim, or clashes with the new design.
3. **Cover with `text-cover` (default for must-go static text):** a premium solid box (dark / white / accent,
   radius ~22) exactly over the old text box (source box × 1.875 + ~10 px) for as long as it is on screen,
   carrying the new line (or empty). `reveal: none` when the old text is visible from the first frame. Cheap,
   reliable, no smears. Rewrite the line in brand voice (e.g. "Any Asian dad…?" → "Dad's next car?").
4. **Inpaint** (`clean.boxes` → `clean_master.sh`, re-grains texture) only when a box would cover the car's key
   detail or the design needs a clean frame (e.g. a hero shot with big type). Zoom-check the result.
5. **Reframe or drop** a moment only if nothing else works.
Text that moves or changes every few seconds (busy text): prefer one cover box sized to the union of its
positions, or inpaint; do not animate one box per caption change.

### 5.8.1 Brand mark and text backgrounds
- **`logo-badge` is the fixed default** brand mark for bulk edits: the authentic logo on its own background
  (dark or white badge) in one corner for the whole main video — always readable, no per-shot work. Choose the
  corner once per batch (top-left unless the source has text there). `logo-top` (no background) is for
  hand-made hero edits only.
- **Text on a background is allowed and often better** (text-cover, verified-feature backing, a small label):
  use it where footage is busy or for a premium label look; keep big hero type (`hero-model`) background-free
  in real negative space. Mix both within a video as the shots demand, never one style everywhere.

### 5.8.2 Two type presets (pick one per video, keep it for the batch where it fits)
- **PUNCH (reference look, default for B&F showcase re-posts):** Montserrat Black / Black Italic / ExtraBold
  (real files in `assets/fonts`) + Manrope for small text. Components: `punch-text` (heavy white line + one
  keyword on a bright pill, group tilted −3…−5°, soft drop shadow), `label-card` (white card, charcoal Black
  title, short subtitle, small coloured tag on the edge, ≤2 ticks), `text-cover` with text, `logo-badge`.
  References: "Iconic Abarth / [Style]", "Perfect for / [City Driving]", "Sporty / [Interior]",
  "Abarth 595 / Small Car. Big Personality." Pill colour: the car's colour when it is vivid (red car → brand
  red `#E8202A`), charcoal `#1F2321` for black/white/silver cars. Use the real italic face for "In the details."
- **CINEMATIC:** Oswald 700 + Manrope (`hero-model`, `detail-line`, `shape-text`) for calm, premium hero shots.
Legibility rules for PUNCH: on blue sky the white line needs nothing; on white cloud, bright walls or
windscreens give line 1 a charcoal backing (`lineBg` 0.45-0.6) — `check` must pass. `logo-badge` style
`clean` (no background, reference look) only on blue/calm skies; otherwise `dark`.
Tags and ticks state only true things ("AT B&F CARS", "FEATURED"); never "NEW ARRIVAL", "SOLD", engine or
economy facts unless verified. **Never leave an empty `text-cover`** — an empty dark box looks crude: always
give it a line (and optional kicker), or inpaint instead.

### 5.9 Human-editor finish (must not look AI-made)
- **Cut on purpose:** cut on music beats and on spoken words (J/L cuts: sound leads the picture by 2–6 frames
  where natural); vary shot lengths (1.2–3.5 s), let one beauty shot breathe 2–3 s with no text.
- **Restraint:** most shots have one small element or none; no element on every shot; no repeating the same
  entrance on every line; no emoji, no stock phrases ("Unleash", "Elevate", "Ultimate"), no "Wait for it…" clichés.
- **Motion that belongs to the footage:** gentle drift that follows the camera's own movement direction; no
  constant zoom-pulse; speed ramps only on a real action moment, at most once.
- **Real sound design:** library SFX (camera, whoosh, punch, click) at low level, matched to an on-screen event;
  room tone under silence; never a whoosh on every cut.
- **Picture:** keep the source's real colour; mild sharpening only (no halos); match all shots' brightness;
  a very light grain (≈2–3 %) can unify upscaled footage; no glow, no light leaks, no AI-style gloss.
- **Voice:** natural British delivery with real pauses; write how a person speaks (short sentences, contractions);
  no hype tone. Captions are plain, readable chunks — no karaoke colour boxes, no bouncing words.
- **Typography craft:** optical alignment to the car/horizon lines, consistent margins, real kerning, no text
  touching edges; two families only; nothing centred by habit.

### 5.10 Colour grading — light, only when it helps
Grade only shots that need it; otherwise leave the footage as shot. Check each shot's frames (and
`ffmpeg -vf signalstats` YAVG/SATAVG): flat, hazy, dull or underexposed shots get a **light** correction;
shots that already look good get none. Correction recipe (start small, compare before/after side by side):
`eq=contrast=1.03-1.06:saturation=1.04-1.08:gamma=0.97-1.0` (plus a touch of `colorbalance` only to remove a
colour cast). Apply via `GRADE="..." bash $VS/scripts/clean_master.sh …` (before upscale) or per shot in the
composition. Rules: keep the real paint colour and skin tones; match all shots in a video to each other; no
looks/LUT styles, teal-orange, crushed blacks, glow or oversaturation — a viewer should not notice a grade,
only that the video looks clean. Note the grade (or "none") in `brief.md`.

| Hero | ~2–4 s | best front 3/4 | `logo-top` + `hero-model` in negative space |

## 7. Brand, dealer credit and claims
- CarVendors.co.uk is the main mark; “Featured dealer: B&F Cars” small and readable. B&F is a featured dealer,
  not the only partner. CarVendors helps people discover/connect; it does not sell the car itself.
- Phone `0330 113 1668` only if confirmed as the current CTA; otherwise `CarVendors.co.uk`.
- `SOURCED & SOLD` only with a documented sale; `AVAILABLE NOW` only with confirmed availability; else no
  stock label. "Free UK-wide car finding" needs a current brief; otherwise "Explore more at CarVendors.co.uk" /
  "Find your next car".
- Do not transcribe or enhance plates unless the job needs it and the text is verified from the footage.
- End cards use **real** showroom photos/clips only. `Showroom Pic/` contains some styled or possibly AI-made
  images (e.g. "Golden Hour…", "Modern UK Car Dealership Showcase"); use files from `orginal img ` or ones the
  user confirms as real. Crop out outdated prices/signage.

## 8. Audio, captions, voice — credit-efficient

### 8.1 Decision tree
1. Listen to the source (Whisper transcript + level). TikTok songs are always removed (rights unknown).
2. Real presenter speech that works → keep and clean; never replace or clone a real person.
3. Ready `Voice/` voiceover → prefer it; **transcribe it and check every fact against the footage** (v001's VO
   said plate "F3 MWN" while the car reads F3 MWW — that phrase was cut from the audio rather than re-voiced).
4. No usable VO → write short, natural UK English (10–25 s) from verified/visible facts.
5. Voice generation: ElevenLabs via `tts.py`, **model chosen per video** (`--list-models`, A/B one short line
   on 2–3 candidates, log the winner in `brief.md`). Same voice for a whole batch. Cache = voice + model +
   text + settings; never re-synthesise for render iterations. No local TTS unless it clearly wins and the
   user agrees (Whisper is the only standard local model).
6. Missing key/tool → continue truthfully without VO, or ask for the one missing thing. Never fake TTS.

### 8.2 Sync and captions
Shot pacing follows the VO; each key phrase gets its matching real footage. Timings from `.words.json` (tts.py)
or Whisper. Captions: spell-checked UK English, 1–2 lines, semantic chunks (`caption-line`, `mount.py --words`).
If a caption and a big headline would overlap, keep the caption and drop the headline.

### 8.3 Music, SFX, loudness
- **Music:** library first — `All Resources/Background Music/Royalty Free Music/` (NCS, Audio Library, YT BG
  Music, Corporate…). Check each track's licence (many "no copyright" tracks still require a credit line in the
  post — add it). Instrumental under speech. ElevenLabs `music.py` only if nothing fits (`voice/music-bed-01.mp3`
  from v001 is already available and reusable).
- **SFX:** library first — `All Resources/Sound Effects/` (whoosh, cinematic whoosh, camera, punch, app click,
  riser…); `sfx.py` only for a missing sound. Max one accent per beat, matched to a visible event.
- **Mix by measurement, not fixed gains:** measure VO and bed loudness (`ffmpeg -af loudnorm=print_format=json`);
  set the bed ≈15–20 LU under the VO while speech plays, lift it in gaps and on the ending; use a
  `data-automation` volume lane; carve with `/hyperframes-audio` `carve.mjs` when available. Hook audio only if
  cleared, limited (sources can peak above 0 dBFS).
- **Master:** two-pass `loudnorm` to I −14 LUFS with a TP target of −2.0 dBTP (AAC encoding adds ~0.5 dB;
  v001 landed at −1.38 with a −1.5 target), AAC 48 kHz 192 kbps, video stream copied. Verify the final file.

## 9. Workflow per video (hand-made path; bulk uses the fast lane §2.1)
1. **Resolve** `paths.py show` + folder N; copy `video.mp4`, `comments.txt`, `Voice/`, chosen hook, logo, showroom photo
   into `input/`.
2. **Evidence:** ffprobe, contact sheet (8–12 frames), Whisper on audio and VO, claims table → `work/analysis/`.
3. **Shots:** cut list with clean ranges (skip the source's own fades), text-box location(s), negative space,
   best hero/detail/interior shots, unusable shots.
4. **Brief** (`brief.md`): type, one-sentence promise, allowed facts, fonts, accent, hook + transition, per-shot
   overlay and §5.8 decision per shot, audio plan, voice model.
5. **Clean master:** `clean_master.sh` → `work/footage/<id>_1080.mp4`; zoom-check the filled area.
6. **Compose** in `work/hf/` (`npx hyperframes init work/hf --non-interactive --example=blank`; copy fonts/brand
   into `work/hf/assets/`): shots as `<video>` clips with `data-media-start`, drift on an outer wrapper, settle
   punch on an inner wrapper, components via `mount.py`, logo, captions, end card.
7. **Audio:** VO/real speech, library bed + SFX, measured ducking lane.
8. **Preflight:** `npx hyperframes lint` → `npx hyperframes check` (0 errors; contrast fixed) → snapshots.
9. **Render:** `npx hyperframes render . -o renders/<id>-raw.mp4 -q delivery` (≈1 min per 30 s on an M3 Pro).
10. **Master audio** (§8.3) → `output/<source-slug>_carvendors_v1.mp4` (then `_v2`…; `_preview` vs `_final`).
11. **QA** (§10) on frames pulled from the rendered file + Whisper on its audio; fix and re-render.
12. **Package:** mp4, contact sheet, `.srt`, brief/evidence notes, social copy (§11).

**Batch of five:** five distinct folders, one manifest row each; same brand logic, fonts, caption system and
voice; different shot plans, hooks and text per footage. Stabilise scripts before paying for VO. QA each video.

## 10. Quality gates
| Check | Pass |
|---|---|
| Authenticity | Real footage/photos only, or disclosed |
| Claims | Price, model/year, engine, stock, plate, promos verified or omitted |
| Old TikTok text | Not readable anywhere; no visible smear at phone size (zoom crops checked) |
| Brand | Authentic CarVendors mark; correct featured-dealer wording |
| Hook → hero | One clear transition onto the strongest real angle |
| Typography | One headline system per shot; ≤2 families; sharp glyphs |
| Contrast | Readable over the whole overlay duration; `check` passes |
| Coverage | No text on headlights, bonnet, wheels, steering wheel, badges or faces |
| Human finish | §5.9 holds: varied rhythm, restraint, no AI tells |
| Safe zones | Right rail/bottom clear; CTA ≥2 s |
| Audio | Speech clear on a phone speaker, no clipping, rights checked, −14 LUFS / ≤ −1.5 dBTP |
| Export | 1080×1920, H.264, synced AAC, no corrupt frames, correct duration |

Frame QA minimum: first frame, first frame after the hook, middle of every scene, brightest text frame,
fastest-motion frame, final CTA frame — all from the rendered MP4, viewed at phone scale.
